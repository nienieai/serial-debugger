# .stlog 格式变更记录

正文在 [stlog-format.md](stlog-format.md)。本文件只记**格式层**的变更，实现进度见文末。

## 版本一览

| 版本 | 日期 | 主要改动 | 为什么 |
|---|---|---|---|
| v1 | 2026-10-29 | 初稿：一个会话一个文件，「头部元数据 + 记录区」的骨架 | 把"历史"从顺手写的文本日志变成可自校验的二进制文件 |
| v1.1 | 2026-10-29 | 头部改双 superblock + 变更日志；去掉 sidecar 索引；写者互斥 / 读者共存 | 头不可写坏、索引可重建；读写并发要比"独占整文件"合理 |
| v1.2 | 2026-10-29 | 双槽**全量快照**（各 4 KB）；头部尺寸固定 8 KB；记录起点定为常量；一层槽 CRC + endMagic | 变更日志（2 次写 + 追加区）比整页覆盖更难保证一致；固定几何让恢复简单 |
| v1.3 | 2026-10-29 | 尾页**整页重写**取代 `dir=0x7F` 填充；Unix 读者不加锁 | 填充记录会累积空洞；读者不加锁才能读正在录的文件，与 Windows `share=READ` 对齐 |
| v1.3.1 | 2026-10-29 | 把"尾页重写"写死：超 `free` 时切分、失败即停录、写前查 `max_size_mb`/`min_free_mb`、前缀必须从磁盘重读、`locked` 探测语义 | 上一版对重写的失败与限额全是"未定义"，实现时会各自发挥 |
| **v1.4** | 2026-10-29 | 数据区改 **4096 B 定长页** + 整页 CRC（页尾 `[4092,4096)`）+ 页头固定统计块 + 记录可跨页分片 + **双影子页**保护尾页；头 8 KB → 16 KB；记录起点 `0x2000` → `0x4000` | 单文件也要能证明"哪一页是完整的"，并把"页级时间过滤 / 列表页"从"解析全部记录"降成"读页头" |
| **v1.4.1** | 2026-10-31 | 槽 payload 由 **JSON 改为 TLV**（`key u16` + `len u16` + 值）；新增 10 项显示设置；`payloadVersion` 2 → 3 | 加字段不必再动版本号：新字段分配一个新 key，老读者跳过即可。JSON 每改一次结构都要升版本、读者还要按版本分支，而当时还没有正式发布的旧文件要照顾 |

被否掉的替代方案（CRC 放页头、统计块自带 CRC、外部统计页、单影子、只在超大帧时切分……）见正文 §17。

> **v2（多文件）**：一个会话改成「manifest + 若干包 + 可重建索引」，包有上限、写满自动新建，
> 帧**允许跨页、禁止跨包**。设计稿见 [stlog-v2.md](stlog-v2.md)，未实现。

## 版本号对照（多处独立，别混用）

| 常量 | 位置 | 当前值 | 什么时候升 |
|---|---|---|---|
| `SlotVer`（slotVersion） | 槽头 `0x0004` | 1 | 槽布局变 |
| `SlotPayloadVer`（payloadVersion） | 槽 payload 的条目 `0x0001` | 3 | payload **编码方式**变才升；加字段只分配新 key，不动这个号（正文 §2.3） |
| `PageVer` | 页头 | 1 | 页布局变 |
| `stats.ver` | 统计块 | 1 | 统计块布局变 |

## 实现进度（0.8.4-dev）

已实现：

- `sessionfile` 包：槽读写/选槽/校验、页读写与整页 CRC、统计块、跨页分片与拼接（含断链）、双影恢复、扫描索引、文本导出
- 槽 payload 的 TLV 编码（v1.4.1）：身份 8 项 + 显示设置 10 项，未知 key 跳过，老 JSON 文件仍可读
- 守护进程录制（跟随 `history.enable`，与 `history/*.log` 同源双写）
- CLI：`stlog-read` / `stlog-verify` / `stlog-dump` / `stlog-export`
- GUI：拖入或选择 `.stlog` 打开只读标签页，分页加载、来源列、导出
- 转发录制：文件头写 `mode` / `portB`，读取侧按记录方向累加 A→B / B→A

未实现（见正文 §5 / §9 / §13）：

- IPC 面 `history.files/open/close/export` 与 replay 会话（现在只能离线读文件）
- `keep_days` 清理、`min_free_mb` 水位、设置页存储区块
- 写协程与尾页缓冲、续写、origin 字典（目前一律内联，见正文 §2.8）
- 边界与性能压测（正文 §12 清单）
